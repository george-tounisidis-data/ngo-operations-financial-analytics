# NGO Operations Financial Analytics
## 📌 Επισκόπηση Έργου
Αυτό το έργο αποτελεί μια ολοκληρωμένη enterprise λύση Business Intelligence που σχεδιάστηκε και υλοποιήθηκε για έναν πραγματικό Μη Κερδοσκοπικό Οργανισμό (ΜΚΟ). Σκοπός του έργου είναι η στρατηγική ανάλυση των μηνιαίων δαπανών, των εξόδων μισθοδοσίας και της κατανομής των λειτουργικών πόρων ανά παράρτημα.

> 🔒 **Σημείωση Ασφάλειας Δεδομένων (Data Anonymization):**
> Για την προστασία των Προσωπικών Δεδομένων (PII) και της εσωτερικής δομής του οργανισμού, όλα τα ευαίσθητα δεδομένα (ονόματα εργαζομένων, συγκεκριμένα έργα και τοποθεσίες γραφείων) έχουν ανωνυμοποιηθεί πλήρως «στον αέρα» (on-the-fly) σε επίπεδο βάσης δεδομένων (SQL Server) πριν τη διασύνδεσή τους με το Power BI. Οι αριθμητικές σχέσεις και τα οικονομικά μεγέθη έχουν διατηρηθεί 100% ατόφια για τη διασφάλιση της ακρίβειας των γραφημάτων.

---

## 🛠️ Τεχνολογικό Stack & Δεξιότητες
* **Database Engine:** Microsoft SQL Server (T-SQL)
* **Analytics & Visualization:** Power BI (Desktop & Power Query)
* **Δεξιότητες:** Data Modeling, Advanced Data Masking, Cost Allocation Logic, CTEs, Window Functions (`DENSE_RANK`).

## 🏗️ Αρχιτεκτονική & Μηχανική Δεδομένων (Data Engineering)

Αντί για την απλή εισαγωγή πινάκων, δημιουργήθηκε ένα βέλτιστο pipeline όπου όλη η βαριά λογική μετασχηματισμού μεταφέρθηκε στην πηγή (Database level).  Ακολουθεί ο T-SQL κώδικας που χρησιμοποιήθηκε για τη δημιουργία των Views της βάσης δεδομένων:

1. **`dbo.vw_Payroll_Anonymized`**:
   * Φιλτράρει και απομονώνει τις δαπάνες προσωπικού από τους εταιρικούς προμηθευτές.
   * Εφαρμόζει dynamic masking χρησιμοποιώντας τη συνάρτηση `DENSE_RANK()` για τη μετατροπή των ονομάτων σε generic κωδικούς (π.χ. "Εργαζόμενος 1", "Έργο 2"), διατηρώντας ακριβείς τις συσχετίσεις και τα counts.

 ```sql
     CREATE VIEW dbo.vw_Payroll_Anonymized AS
SELECT 
    -- 1. Ανωνυμοποίηση Έργου (π.χ. Έργο 1, Έργο 2)
    N'Έργο ' + CAST(DENSE_RANK() OVER (ORDER BY [Έργο]) AS NVARCHAR(10)) AS [Πρόγραμμα/Έργο],
    
    -- 2. Ανωνυμοποίηση Εργαζόμενης (π.χ. Εργαζόμενος 1, Εργαζόμενος 2)
    N'Εργαζόμενος ' + CAST(DENSE_RANK() OVER (ORDER BY [Επωνυμία/Ονοματεπώνυμο]) AS NVARCHAR(10)) AS [Εργαζόμενη],
    
    MONTH([Ημ/νία]) AS [Μήνας], 
    
    -- 3. Τα οικονομικά ποσά παραμένουν ατόφια
    SUM([Συνολική αξία ]) AS [Συνολικό Ποσό Χρέωσης],
    
    COUNT(*) AS [Πλήθος Παραστατικών]
FROM dbo.EBS
WHERE [Έργο] IS NOT NULL 
  AND [Επωνυμία/Ονοματεπώνυμο] IS NOT NULL
  
  -- Φίλτρα Εταιρειών & Σταθερών Δαπανών
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΕΝΟΙΚΙΟ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΕΝΟΙΚΙΑ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΕΥΔΑΠ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΟΤΕ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%COSMOTE%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%VODAFONE%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%WIND%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΔΕΗ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΑΕΡΙΟ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΚΟΙΝΟΧΡΗΣΤΑ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΤΑΧΥΔΡΟΜΕΙΑ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΤΕΛΗ ΚΥΚΛΟΦΟΡΙΑΣ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΕΞΟΔΑ ΕΠΟΜ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΤΡΑΠΕΖΑ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΣΚΛΑΒΕΝΙΤΗΣ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΠΛΑΙΣΙΟ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ZOOM%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%MAILCHIMP%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%FACEBOOK%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%STRIPE%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%WATERFRESH%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΠΑΡΚ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%VOICELAND%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%OFFICEMARKET%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%GFORGADGET%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%LINKABLE%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%SUSAMI%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΚΑΛΛΙΑΝΕΣΗΣ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%PROGRESS NET%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ALPHA ΤΡΑΠΕΖΑ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%STELLAR%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%μικροπιστωτές%'

  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΕΕ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%Ε.Ε%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΑΕ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%Α.Ε%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΕΠΕ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%Ε.Π.Ε%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΙΚΕ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%Ι.Κ.Ε%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΙΔΙΩΤΙΚΗ ΚΕΦΑΛΑΙΟΥΧΙΚ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%ΜΟΝΟΠΡΟΣΩΠΗ%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%I K E%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%I.K.E%'

  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%E.E%'
  AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%LTD%'
GROUP BY [Έργο], [Επωνυμία/Ονοματεπώνυμο], MONTH([Ημ/νία])
```

2. **`dbo.vw_Expenses_Anonymized`**:
   * Ομαδοποιεί τα πάγια έξοδα σε στρατηγικές κατηγορίες (Ενοίκια, Ενέργεια, Τηλεπικοινωνίες).
   * Ενσωματώνει **Advanced Cost Allocation Logic** (μέσω CTE & `UNION ALL`), παίρνοντας σύνθετους λογαριασμούς (όπως Voiceland), διααιρώντας τους ισομερώς (`/ 4.0`) και επιμερίζοντάς τους αυτόματα στα 4 διαφορετικά γεωγραφικά παραρτήματα.

```sql
ALTER VIEW dbo.vw_Expenses_Anonymized AS
WITH RawExpenses AS (
    SELECT 
        CASE 
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%Διεύθυνση 1%' THEN N'Γραφείο 1'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%Διεύθυνση 2%' THEN N'Γραφείο 2'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%Διεύθυνση 3%' THEN N'Γραφείο 2'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%Διεύθυνση 4%' THEN N'Γραφείο 3'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΚΕΝΤΡΙΚΟ%' THEN N' Γραφείο 4'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%Διεύθυνση 5%' THEN N'Γραφείο 4'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΕΔιεύθυνση 6%' THEN N' Γραφείο 4'
            ELSE N'Γραφείο 4'
        END AS [Παράρτημα/Γραφείο],
        CASE 
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΕΝΟΙΚΙΟ%' OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΕΝΟΙΚΙΑ%' THEN N'Ενοίκια'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΚΟΙΝΟΧΡΗΣΤΑ%' THEN N'Κοινόχρηστα'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΔΕΗ%' OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΑΕΡΙΟ%' OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΕΥΔΑΠ%' THEN N'Ενέργεια & Κοινή Ωφέλεια'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΟΤΕ%' OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%COSMOTE%' OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%VODAFONE%' OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%WIND%' THEN N'Τηλεπικοινωνίες'
            ELSE N'Λοιπά Λειτουργικά'
        END AS [Κατηγορία Εξόδου],
        
        -- 🌟 ΠΡΟΣΘΗΚΗ: Παίρνουμε τον Μήνα από την ημερομηνία
        MONTH([Ημ/νία]) AS [Μήνας],
        
        SUM([Συνολική αξία ]) AS [Συνολικό Κόστος]
    FROM dbo.EBS
    WHERE 
        ([Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΕΝΟΙΚΙΟ%'
        OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΕΝΟΙΚΙΑ%'
        OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΚΟΙΝΟΧΡΗΣΤΑ%'
        OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΔΕΗ%'
        OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΑΕΡΙΟ%'
        OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΕΥΔΑΠ%'
        OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΟΤΕ%'
        OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%COSMOTE%'
        OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%VODAFONE%'
        OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%WIND%')
        AND [Επωνυμία/Ονοματεπώνυμο] NOT LIKE N'%VOICELAND%'
    GROUP BY 
        CASE 
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%Διεύθυνση 1%' THEN N'Γραφείο 1'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%Διεύθυνση 2%' THEN N'Γραφείο 2'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%Διεύθυνση 3%' THEN N'Γραφείο 2'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%Διεύθυνση 4%' THEN N'Γραφείο 3'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΚΕΝΤΡΙΚΟ%' THEN N' Γραφείο 4'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%Διεύθυνση 5%' THEN N'Γραφείο 4'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΕΔιεύθυνση 6%' THEN N' Γραφείο 4'
            ELSE N'Γραφείο 4'
        END,
        CASE 
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΕΝΟΙΚΙΟ%' OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΕΝΟΙΚΙΑ%' THEN N'Ενοίκια'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΚΟΙΝΟΧΡΗΣΤΑ%' THEN N'Κοινόχρηστα'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΔΕΗ%' OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΑΕΡΙΟ%' OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΕΥΔΑΠ%' THEN N'Ενέργεια & Κοινή Ωφέλεια'
            WHEN [Επωνυμία/Ονοματεπώνυμο] LIKE N'%ΟΤΕ%' OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%COSMOTE%' OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%VODAFONE%' OR [Επωνυμία/Ονοματεπώνυμο] LIKE N'%WIND%' THEN N'Τηλεπικοινωνίες'
            ELSE N'Λοιπά Λειτουργικά'
        END,
        MONTH([Ημ/νία]) -- 🌟 ΠΡΟΣΘΗΚΗ στο Group By

    UNION ALL

    -- 🌟 ΠΡΟΣΘΗΚΗ: MONTH([Ημ/νία]) και GROUP BY MONTH στα 4 SELECT της Voiceland
    SELECT N'Γραφείο 4' AS [Παράρτημα/Γραφείο], N'Τηλεπικοινωνίες' AS [Κατηγορία Εξόδου], MONTH([Ημ/νία]) AS [Μήνας], SUM([Συνολική αξία ]) / 4.0 AS [Συνολικό Κόστος] FROM dbo.EBS WHERE [Επωνυμία/Ονοματεπώνυμο] LIKE N'%VOICELAND%' GROUP BY MONTH([Ημ/νία])
    UNION ALL
    SELECT N'Γραφείο 1' AS [Παράρτημα/Γραφείο], N'Τηλεπικοινωνίες' AS [Κατηγορία Εξόδου], MONTH([Ημ/νία]) AS [Μήνας], SUM([Συνολική αξία ]) / 4.0 AS [Συνολικό Κόστος] FROM dbo.EBS WHERE [Επωνυμία/Ονοματεπώνυμο] LIKE N'%VOICELAND%' GROUP BY MONTH([Ημ/νία])
    UNION ALL
    SELECT N'Γραφείο 2' AS [Παράρτημα/Γραφείο], N'Τηλεπικοινωνίες' AS [Κατηγορία Εξόδου], MONTH([Ημ/νία]) AS [Μήνας], SUM([Συνολική αξία ]) / 4.0 AS [Συνολικό Κόστος] FROM dbo.EBS WHERE [Επωνυμία/Ονοματεπώνυμο] LIKE N'%VOICELAND%' GROUP BY MONTH([Ημ/νία])
    UNION ALL
    SELECT N'Γραφείο 3' AS [Παράρτημα/Γραφείο], N'Τηλεπικοινωνίες' AS [Κατηγορία Εξόδου], MONTH([Ημ/νία]) AS [Μήνας], SUM([Συνολική αξία ]) / 4.0 AS [Συνολικό Κόστος] FROM dbo.EBS WHERE [Επωνυμία/Ονοματεπώνυμο] LIKE N'%VOICELAND%' GROUP BY MONTH([Ημ/νία])
)
SELECT 
    N'Γραφείο ' + CAST(DENSE_RANK() OVER (ORDER BY [Παράρτημα/Γραφείο]) AS NVARCHAR(10)) AS [Παράρτημα/Γραφείο],
    [Κατηγορία Εξόδου],
    [Μήνας], -- 🌟 ΠΡΟΣΘΗΚΗ στο τελικό Select
    [Συνολικό Κόστος]
FROM RawExpenses;
GO
```

## 📊 Το Power BI Dashboard
Το dashboard προσφέρει πλήρη εποπτεία των δεδομένων στη διοίκηση της ΜΚΟ, επιτρέποντας:
* **Κατανομή Ανθρώπινου Δυναμικού (Resource Allocation):** Πλήρης αποτύπωση της απασχόλησης των εργαζομένων ανά πρόγραμμα, με ακριβή προσδιορισμό του ποσοστού συμμετοχής τους.
* **Παρακολούθηση Μηνιαίας Τάσης (Trend Analysis):** Ανάλυση της διακύμανσης των αμοιβών ανά μήνα για την πρόβλεψη του cash flow.
* **Ανάλυση Κόστους ανά Παράρτημα:** Δομημένη σύγκριση των συνολικών εξόδων (Γραφείο 1 έως 4) για τον εντοπισμό αποκλίσεων από τον προϋπολογισμό.
* **Κατανομή Δαπανών:** Πλήρης διαφάνεια στο πού ξοδεύονται οι πόροι της ΜΚΟ (Λειτουργικά, Ενοίκια, Τηλεπικοινωνίες).
